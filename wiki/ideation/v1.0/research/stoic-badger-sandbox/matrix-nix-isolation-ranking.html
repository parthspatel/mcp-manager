Interactive isolation-strategy matrix

Eight strategies, eight criteria, all scores backed by an evidence link. Drag the weight sliders to see how the ranking shifts when you favour reproducibility over install friction, or vice versa.

How to read this

  • Scores 0–5 per option / criterion. 5 means "best in class for this criterion;" 0 means "this option doesn't really do this."
  • Weights sum to ~1.0 by default. Move sliders to re-weight.
  • Evidence: each numeric score has bracketed links pointing back to the citation that justifies the score.
  • The reset button restores the default weights, which reflect a security-leaning bias (reproducibility + isolation are heaviest).

Default-weight headline

With the default weighting, devenv + OS sandbox leads on the strength-of-evidence side: build-time reproducibility from Nix plus run-time scoping from whichever OS sandbox is available. Docker MCP Toolkit and Podman rootless sit close behind as the cross-platform escape hatches. OS native install ranks last on both the threat-model criteria.

What happens if you reweight

  • Maximise install friction (low) and dev ergonomics: raw npx/uvx rises sharply — at the cost of the threat-model score.
  • Maximise cross-platform parity: Docker wins, because it is the most uniform across Linux/macOS/Windows.
  • Maximise startup latency: bubblewrap+uvx and sandbox-exec+uvx top out, because native exec beats container cold-starts.
  • Maximise reproducibility: devenv-based options dominate by design.

Caveats around the scoring

  • Subjectivity: scores were calibrated against the cited sources, but five judges would produce five slightly different matrices. The reader is invited to re-score; the data/nix-isolation-ranking.json file is plain JSON.
  • Recency: Docker MCP Toolkit, devenv, and SecretSpec all moved fast in 2025-26 — scores reflect the cited 2026-05-24 snapshot.
  • Combo strategies: the matrix treats “bubblewrap + uvx” as one row to keep things finite, but a real deployment could mix-and-match.
