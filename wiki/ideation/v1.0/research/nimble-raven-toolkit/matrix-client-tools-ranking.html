Ranking matrices — CLI · TUI · GUI

Three independent weighted-scoring matrices, one per surface. Scores are 0–5 with weights summing to ~1.0; drag the sliders to re-rank live. [1]-style evidence links jump to the matching citation footnote at the bottom of the page. The defaults reflect the stream's own assumptions about what matters for the MCP Manager — none of them are objectively correct.

CLI — Rust argument parsers

The CLI is the surface with the strongest ecosystem gravity and the lowest framework risk. The matrix weights developer experience, feature breadth, and community/ecosystem heavily because the cost of every wrong choice in this layer compounds across every subcommand, and because the operator-facing UX (help text, completions, conventions) is what users will interact with daily. Compile time and binary size are weighted modestly — they matter, but only enough to flag clap (full)'s costs, not to override its other strengths.

TUI — Rust terminal frameworks

For the TUI, the question isn't "is ratatui the right pick?" but "which ratatui flavor?" The matrix weights community/ecosystem, cross-platform coverage, and production track record heavily because the MCP Manager TUI's most direct architectural ancestors (bottom, gitui, k9s) live in exactly those dimensions. Mouse support and async are scored but lightly weighted — every modern backend supports both.

GUI — Rust GUI frameworks

The GUI matrix is where the rankings move the most when you adjust weights, which is why the recommendation page is explicit about volatility. The default weights here treat cross-platform coverage, API stability, community, and accessibility as the four pillars; theming and async support are secondary. Push accessibility up and Slint and Tauri rise; push binary size up and Slint and the pure-native options rise; push community up and Tauri wins comfortably. The point of the live sliders is to make those sensitivities visible rather than baked-in.

How to read the rankings together

The CLI matrix is essentially noise above clap (derive) — any reasonable weight setting puts it on top, which matches the ecosystem consensus . The TUI matrix similarly favors ratatui + crossterm across all reasonable weightings, with tui-realm moving up only if "developer experience" and "learning curve" weights are raised. The GUI matrix is the one with genuine sensitivity — Tauri 2 and Slint trade the top spot depending on whether you privilege ecosystem reach or pure-native efficiency and theming, and egui climbs only if a11y is weighted heavily and license restrictions disqualify Slint.
