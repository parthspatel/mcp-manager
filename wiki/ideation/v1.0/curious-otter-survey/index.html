Stream summary

Every major MCP host today owns its own JSON (or YAML) config file in a different location, with a slightly different schema (mcpServers vs servers vs context_servers vs extensions), and an inconsistent transport story: most support stdio universally, Streamable HTTP is becoming standard, and the legacy HTTP+SSE form is being phased out. Secrets are almost always stored as plaintext in those JSON files; OS-keychain support is the exception (Anthropic's DXT bundles, VS Code inputs) rather than the rule. Real-world friction shows up at the seams: PATH inheritance failures, MSIX virtualization writing to the wrong file, sequential server shutdown blocking app quit, no live restart, and zero portability of config across hosts. These are the gaps the MCP Manager will be measured against.
