Stream 4 — Client API surface (CLI ↔ TUI ↔ GUI ↔ Core)

This stream designs the internal API the MCP Manager core exposes to its own CLI, TUI, and GUI clients — analogous to docker ↔ dockerd or kubectl ↔ kube-apiserver. It is not the MCP protocol itself (that wire lives between MCP hosts and MCP servers). The stream picks an IPC channel, a serialization format, a streaming model, an auth model, and a versioning policy that all three clients can speak.

Pages in this stream

  • Required operations — resources, methods, request/response sketches
  • Live updates — gRPC streams, SSE, WebSockets, NDJSON, MessagePack streams
  • Local auth — socket permissions, bearer tokens, peer creds, FD passing
  • Schema evolution — protobuf, Cap'n Proto, OpenAPI, JSON Schema
