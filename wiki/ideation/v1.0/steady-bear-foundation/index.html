steady-bear-foundation — Core architecture

Stream 3 of 5. This stream maps the design space for the Rust core of MCP Manager — the part that installs, starts, supervises, and tracks MCP servers, and that every other surface (CLI / TUI / GUI) talks to. We compare prior art (dockerd, containerd, podman, systemd, launchd, nix-daemon, lima, mcp-inspector, uvx/pipx), survey the Rust runtime / supervision / state / transport / packaging primitives, weigh five architectural archetypes in an interactive matrix, and end with a concrete workspace layout and a daemon-vs-library call.
