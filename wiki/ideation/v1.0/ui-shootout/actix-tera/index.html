Stack: Actix-Web + Askama (localhost SSR)

This stack is the deliberate odd-one-out of the UI shootout. Where Tauri+Leptos and Tauri+Dioxus give you a native window with a WebView inside it, this stack gives you a Rust HTTP server on 127.0.0.1:NNNN and a browser tab. The model is Jellyfin, Sonarr, Pi-hole, FastAPI's /docs — a long-lived daemon with a web admin UI, not a desktop application. For MCP Manager — where a long-lived daemon (mcpd) already exists — the GUI can literally be mcpd's HTTP front-end .

What you get

LayerChoiceWhy
HTTP serverActix-Web 4.xMature, fastest Rust framework on TechEmpower, native SSE via actix-web-lab .
TemplatesAskama (compile-time, type-checked)Templates bind to Rust structs; the compiler catches missing fields and the mcpd domain model flows straight into the view layer . Tera is the strong runtime alternative .
InteractivityHTMX + Alpine.js (light JS)HTMX handles SSE log tails and partial swaps; Alpine handles client-only UI (modals, dropdowns) .
Traytray-icon (optional, in-process)Cross-platform tray menu (Quit, Open in browser, Restart). macOS main-thread caveat .
Real-timeSSE (HTTP/1.1)tokio broadcast channel + actix-web-lab Sse helper + heartbeat ping — log tails and status are one-liners .

The one-line case for this stack

If the goal is to ship a working MCP Manager v1.0 in weeks with screen-reader-grade accessibility for free, real-time updates as the native idiom, a single Rust binary, and a credible mobile path on day one — and you can stomach the fact that the UI is a browser tab and not a native window — this is the lowest-risk choice on the board.
