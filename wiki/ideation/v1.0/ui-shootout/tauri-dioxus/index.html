Tauri 2 + Dioxus — stack evaluation

This branch of the GUI shootout evaluates Dioxus — a React-shaped, fullstack Rust UI framework — as the renderer for the MCP Manager GUI. Dioxus ships several renderers (WebView desktop, web/WASM, liveview, and the new Blitz/Native GPU renderer in 0.7) plus an opinionated CLI (dx) with Subsecond hot-patching of live Rust code. We evaluated it both wrapped in Tauri 2 and standalone via dioxus-desktop.

Bottom line up front: dioxus-desktop standalone (no Tauri wrapper) is the right call. It already uses Wry/Tao under the hood — the same WebView engine Tauri uses — so wrapping it in Tauri adds ceremony with no meaningful upside for a macOS+Linux v1.0. Blitz/Dioxus Native is fascinating but pre-alpha; not for v1. See the recommendation page for the full argument.

Verdict at a glance

Best when: small Rust-fluent team values a single-language stack, fast iteration via Subsecond, and is fine with the system WebView.

Worst when: you need bulletproof CSS across exotic widgets, a deep ecosystem of vetted security primitives, or you plan to migrate off WebView to a true native UI before 2027.

Recommended flavor: dioxus-desktop standalone — Tauri wrapping adds glue with no clear benefit on macOS+Linux. dioxus-native/Blitz is pre-alpha and not ready.
