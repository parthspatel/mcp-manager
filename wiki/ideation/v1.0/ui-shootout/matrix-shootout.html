GUI shootout — interactive ranking matrix

Three GUI stacks × 13 weighted criteria. Drag the weight sliders to re-rank live. Default weighting reflects the "OBSESSED about UX" product direction — live updates, accessibility, dev experience, IPC ergonomics, and first-paint are up-weighted.

Each score is taken from the corresponding agent's data/scorecard.json. Numeric dimensions (binary size, memory at idle, first paint) are normalized to 1–10 with the conversion table at the bottom of the page.

How to read this

Each column is one stack's score across all criteria; each row is one criterion's scores across all stacks; weights sum to 1.000. The weighted total at the bottom is sum(weight × score) per stack — the higher the better.

Use the sliders to test sensitivity: if you'd weight "feels like a real app" (the theming_native_feel row) much higher than the default 0.08, the ranking shifts. Specifically, around weight ≈ 0.30 on that single criterion, Dioxus-desktop overtakes Actix+Askama. See the shootout hub's sensitivity analysis for a discussion.
